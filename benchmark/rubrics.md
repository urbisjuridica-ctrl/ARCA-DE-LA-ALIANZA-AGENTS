# Rubrics – ARCA-DE-LA-ALIANZA Hermeneutics Benchmark v1

Score each dimension from **0 to 5**.

## 1. Role Identification (Heket / Negra Nueva / Negra Vieja)

| Score | Criteria |
|-------|----------|
| 5 | Clear functional distinction: Negra Vieja = dormant archaic memory; Negra Nueva = suffering/gestating flesh; Heket = midwife of the pneuma / pure flow |
| 4 | Correct assignment with minor imprecision |
| 3 | Partially correct, some confusion between figures |
| 2 | Major confusion or superficial treatment |
| 1 | Figures misidentified or ignored |
| 0 | No attempt |

| Score | Criteria |

| Score | Criteria |
